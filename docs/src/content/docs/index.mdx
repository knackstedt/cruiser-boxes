## What is Cruiser?

Cruiser is a WinBoat-style QEMU/KVM manager for **Linux guests**. WinBoat wraps
QEMU in Docker because Windows needs an appliance boundary — Linux guests need
none of that. Cruiser drives QEMU directly over its QMP/QGA unix sockets, so
lifecycle, hotplug, snapshots, and in-guest exec are all first-class, and
daemonized VMs survive app restarts by reattaching to their sockets.
